## 一、模型、训练与推理

深度学习里的「模型」，本质上是一组复杂的数学计算步骤。用最简单的线性方程 `y = ax + b` 来类比：给定 a、b，代入 x 得到 y，这个过程就是**推理**。但在大模型场景里，输入输出都是高维矩阵，还需要叠加非线性变换（如 `y = σ(ax + b)`），这样的最小单元被称为一个「神经元」，大模型就是大量神经元组合而成。

我们并不知道真实存在的 a、b，但可以借助数据去逼近它们：给模型足够多的「输入 x → 期望输出 y」样例，通过优化算法不断调整参数，使输出尽量符合预期。这个反推参数的过程就是**训练**，数学上称为拟合。

### 预训练、微调与人类对齐

按数据类型，训练大致分为三个阶段：

- **预训练**：利用互联网上大量无标注文本（如续写、填空类任务），让模型抽象出语言的通用规律。成本最高，往往需要几千张显卡、数 TB 数据。
- **微调**：用「问题 — 答案」这类标注数据继续训练，使模型具备问答能力。
- **人类对齐**：用「正确答案 + 错误答案」的数据，让模型学会以人类期望的方式回答，技术门槛最高，通常由模型提供方完成。

只做过预训练（或加通用微调）的通常称为 **base 模型**，知识面广但可能答非所问；完成对齐后的称为 **chat 模型**，可直接用于通用问答。

### 推理的一般过程

句子先经 **Tokenizer** 按词表切分并映射为 token 索引，再把每个标量映射为高维向量（如 5120 维），得到一个 `序列长度 × 维度` 的矩阵。矩阵在模型内部经过层层计算后，输出一个与词表等长的向量，经 softmax 概率化后取概率最大的索引，查表还原成文字。把这个生成的字再拼回输入、继续预测下一个字，就是**自回归**；遇到结束符 `eos_token` 即停止。

## 二、Transformer 的基本结构

以 LLaMA2 的结构为例，整体流程如下：

1. 输入句子经 Tokenizer 变成 tokens；
2. 经过 Embedder，token 转为浮点 tensor；
3. 进入若干 layer，每层包含 **Attention** 结构：计算 Q 与 K 的内积并概率化，再乘对应的 V，得到新的 tensor；
4. 与输入 x 相加（残差连接，缓解深层梯度消失），再做 **Normalization**；
5. 进入 **FeedForward（MLP）**，然后送入下一层；
6. 所有层计算完成后，经一个 linear 输出词表中每个位置的概率。

其核心思想是：让每个字的 tensor 与其他字的 tensor 做内积（类似 cosine 投影，衡量相关程度），再把相关程度归一化成占比，按比例加权求和，得到一个新的 tensor——它是对整个句子所有字的一种抽象混合。每个字都做同样的事，因此输出序列长度与输入一致；层数越深，抽象出的语义越深。

### 相比 CNN 与 LSTM 的优势

- **CNN** 具有局部性与平移不变性，关注局部信息，小样本下有归纳偏差优势，但容易忽略全局关系。
- **LSTM** 的长距离记忆会加速遗忘最早的 token，且只能单向注意，理解存在偏差；双向 LSTM 的大规模分布式训练又很困难。
- **Transformer** 不预设归纳偏差，需要大数据量，但对 token 可**并行计算**，分布式训练友好，加上内置位置编码，较好解决了注意力的位置不敏感问题，因而在数据充足的时代异军突起。

## 三、Encoder 与 Decoder

原始 Transformer 由左侧 Encoder 与右侧 Decoder 组成，但今天的大模型几乎清一色是 **Decoder-only** 结构，原因大致有二：

1. Decoder 结构更简单，分布式训练更容易；Encoder-Decoder 结构复杂，工程与成本代价高。
2. 有论文指出，当参数量增大时 Encoder-Decoder 不再具有显著优势，其收益甚至可能仅仅来自参数翻倍。

以 LLaMA2 为例，它的几个工程特点值得关注：

- 用 **RMSNorm** 替代 LayerNorm 做预归一化；
- 使用 **RoPE**（旋转位置编码）；
- MLP 使用 **SwiGLU** 激活函数；
- 大参数量版本使用 **GQA**（分组查询注意力）。

### RMSNorm

RMSNorm 的作者发现，LayerNorm 中减去均值做中心偏移意义不大，于是简化为仅按均方根缩放：

```
ā_i = a_i / RMS(a) * g_i,  RMS(a) = sqrt(1/n * Σ a_i²)
```

在效果基本不变的前提下，计算时间可提升约 40%。

### RoPE 与位置编码

早期 BERT 使用 Sinusoidal 位置编码，将位置信息**加**到 embedding 上，具备一定外推特性。ALiBi 则不在 embedding 上加，而是在 Q·K 的结果上叠加位置矩阵，外推更稳定。

**RoPE（旋转位置编码）** 的不同之处在于位置编码是**乘性**的，两个向量间表现为角度差，几何意义清晰。其位置编码矩阵是单位正交阵，乘上后不改变向量模长，且相比 Sinusoidal 具备更好的外推特性。

### SwiGLU

SwiGLU 是 GLU 结构的变种，把其中的激活函数换成 SiLU。论文中论证它在 loss 收益上显著优于 ReLU、GeLU、LeakyGeLU 等方法。

### GQA

- **MHA**：标准多头注意力，每个头都有独立的 Q、K、V。
- **MQA**：共享所有头的 KV，仅为每个头保留独立 Q，减少显存占用。
- **GQA**：在 MQA 基础上分组，组内共享 KV，是显存与效果之间的折中。LLaMA2 的 70B 版本采用了 GQA 以提升推理性能。

## 四、ChatGLM2 的结构差异

ChatGLM2 与 LLaMA2 结构相近，主要不同点：

- 未使用 GQA，而是采用 **MQA**；
- QKV 为单一矩阵，对 hidden_state 整体仿射后再拆分为 Query、Key、Value；
- MLP 未使用 Up/Gate/Down 三个 Linear 加 SwiGLU，而是先用 `hidden_size → 2 × ffn_hidden_size` 的上采样，拆成两个宽度为 `ffn_hidden_size` 的 tensor 后直接过 SiLU，再经下采样 Linear 输出。

## 小结

Transformer 用自注意力取代循环与卷积，换来了并行化与可扩展性，成为今天大语言模型的基石。理解 Q/K/V、位置编码与归一化等组件，是读懂现代 LLM 结构的第一步。后续我会继续整理 Attention 细节与训练实践，欢迎交流。
